# Política de privacidade

_Última atualização: 2026-10-14_

O **content-factory** é uma ferramenta de pesquisa de conteúdo operada por
uma única pessoa (o mantenedor deste repositório). Ela não tem usuários
finais, não oferece login a terceiros e não publica, comenta, curte nem
envia mensagens em nenhuma plataforma.

## Que dados lemos

Pela Instagram Graph API, usando apenas a conta do próprio operador, a
ferramenta lê **conteúdo público** das hashtags de nicho que monitora
(por exemplo, velas e sabonetes artesanais):

- identificador, link permanente, tipo de mídia, data de publicação e
  miniatura do post;
- legenda e contagens públicas de curtidas e comentários;
- nome de usuário público da conta que publicou.

Não lemos mensagens, dados de seguidores, e-mails, telefones nem qualquer
dado privado.

## Para que usamos

Exclusivamente para análise agregada de tendências de conteúdo do nicho
(quais formatos e temas performam melhor). Os dados não são vendidos,
compartilhados, usados para publicidade nem para contatar pessoas.

## Onde ficam e por quanto tempo

Em um banco de dados privado do operador, sem acesso público. Os dados são
mantidos apenas enquanto forem úteis à análise e removidos ao fim de cada
ciclo de pesquisa ou a pedido (veja abaixo).

## Exclusão de dados

Qualquer pessoa pode pedir a remoção dos registros associados ao seu nome de
usuário. Instruções em [Exclusão de dados](exclusao-de-dados.md).

## Privacy policy (English summary)

content-factory is a single-operator content research tool. It has no end
users, offers no third-party login and never publishes, comments, likes or
sends messages. Through the Instagram Graph API, using only the operator's
own account, it reads **public** posts from a small set of niche hashtags
(post id, permalink, media type, timestamp, thumbnail, caption, public like
and comment counts, and the public username of the author). Data is used
only for aggregate trend analysis, is never sold or shared, is stored in a
private database and is deleted at the end of each research cycle or on
request — see [Data deletion](exclusao-de-dados.md).
